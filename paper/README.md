# Paper — AAAI-27 AISI submission

Draft manuscript for the AAAI-27 Special Track on AI for Social Impact (AISI).

- `democracy_bench.tex` — the manuscript (double-blind `[submission]` format).
- `references.bib` — bibliography (all entries verified against primary sources; two
  recent-preprint entries carry `note` reminders to reconfirm venue before camera-ready).

## Building

The AAAI-27 style files are **not committed** (they are AAAI-copyrighted, distributed via
the Author Kit). Before building, drop these two files from the **AAAI-27 Author Kit** into
this directory:

- `aaai2027.sty`
- `aaai2027.bst`

Then:

```
latexmk -pdf democracy_bench.tex
```
